# FontBlush

FontBlush is a free collection of Unicode text tools. You type or pick, then copy and paste the result anywhere.

## What's inside
- Cute symbols: https://fontblush.com/cute-symbols/
- Bow symbols: https://fontblush.com/bow-symbols/
- Cute emoticons: https://fontblush.com/cute-emoticons/
- Full tool list: https://fontblush.com

## How it works
Unicode characters are plain text, so the styled output works in most bios, usernames and captions. No signup and no download.

## Notes
Some apps and older devices don't display every Unicode character. If a symbol shows as a box, pick another one.
